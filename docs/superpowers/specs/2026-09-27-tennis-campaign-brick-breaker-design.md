# 테니스 캠페인형 3D 벽돌깨기 설계

## 목표

현재 Three.js 브릭 브레이커 프로토타입을 한 판을 시작하고, 벽돌을 깨고, 승리하거나 목숨을 모두 잃은 뒤 다시 시작할 수 있는 완결된 게임으로 확장한다. 시각적으로는 3D 테니스 코트와 캠페인형 인터페이스의 분위기를 사용하되, 라코스테의 로고·상표·외부 이미지·외부 3D 모델은 복제하거나 사용하지 않는다.

## 범위

포함하는 기능은 다음과 같다.

- 3D 벽돌 배열과 공-벽돌 충돌
- 벽돌 파괴, 점수 증가, 짧은 파편 효과
- 목숨 3개와 공 재배치
- 시작, 플레이, 승리, 게임오버 상태
- 시작 및 결과 오버레이와 다시 시작 버튼
- 짙은 테니스 그린, 크림색 코트 라인, 노란 공을 활용한 캠페인형 시각 디자인
- 기존 키보드·모바일 터치 조작
- 기존 2D·3D 시점 전환
- 기존 패들 운동량 기반 공 가속

이번 범위에서는 파워업, 멀티볼, 레이저, 실드, 여러 레벨, 외부 에셋, 온라인 순위표를 구현하지 않는다.

## 게임 규칙

1. 첫 화면에서 사용자가 `게임 시작`을 누르면 공이 움직이기 시작한다.
2. 공이 벽돌에 닿으면 충돌한 벽돌 하나가 제거되고 점수가 증가한다.
3. 제거된 위치에는 수명이 짧은 Geometry 파편이 생성된다.
4. 공이 패들 아래로 빠지면 목숨이 하나 줄고 공과 패들이 시작 위치로 돌아간다.
5. 남은 목숨이 있으면 짧은 준비 상태 뒤 사용자가 다시 시작한다.
6. 모든 벽돌을 제거하면 승리 상태가 된다.
7. 목숨이 0이면 게임오버 상태가 된다.
8. 승리 또는 게임오버 화면의 `다시 시작`은 벽돌, 점수, 목숨, 공 속도와 위치를 모두 초기화한다.

벽돌 하나는 100점이다. 초기 목숨은 3개이며 한 레벨만 제공한다.

## 구조

### `objects/Brick.ts`

하나의 벽돌 Mesh와 충돌에 필요한 크기, 활성 상태, 점수 값을 관리한다. Geometry와 Material 정리도 담당한다.

### `objects/BrickField.ts`

설정에 따라 벽돌을 행과 열로 생성하고 Scene에 연결한다. 활성 벽돌 목록, 남은 벽돌 수, 전체 재생성과 자원 해제를 제공한다.

### `effects/BrickBurst.ts`

벽돌 파괴 위치에 작은 BoxGeometry 조각을 생성한다. 각 조각은 속도와 남은 시간을 가지며 매 프레임 이동·회전·투명화된다. 수명이 끝나면 Scene과 GPU 자원에서 제거된다.

### `systems/GameState.ts`

`ready`, `playing`, `won`, `game-over` 상태와 점수, 목숨을 관리한다. 점수 변경, 목숨 감소, 재시작을 한곳에서 처리하고 UI가 읽을 수 있는 스냅샷을 제공한다.

### `systems/CollisionSystem.ts`

기존 벽·패들 충돌에 공-벽돌 충돌을 추가한다. 공의 중심에서 벽돌 AABB의 가장 가까운 점을 구해 충돌을 판정하고, 최소 침투 축에 따라 X 또는 Z 속도를 반전한다. 한 프레임에서 같은 벽돌을 두 번 제거하지 않는다.

### `game/Game.ts`

BrickField, BrickBurst, GameState를 조립한다. `playing` 상태에서만 패들·공·충돌을 갱신하고, 충돌 이벤트를 점수·목숨·승패 상태로 변환한다. UI에는 콜백으로 상태를 전달한다.

### `main.ts`와 `index.html`

점수, 남은 목숨, 시작·결과 오버레이를 관리한다. 버튼 이벤트를 Game의 시작 및 재시작 메서드에 연결하고 `aria-live`로 점수와 상태 변경을 전달한다.

## 데이터 흐름

```text
키보드/터치 입력
  → Paddle 이동 및 속도 계산
  → Ball 이동
  → CollisionSystem 충돌 계산
  → 벽돌 제거 이벤트 / 공 리셋 이벤트
  → GameState 점수·목숨·승패 갱신
  → HUD와 오버레이 갱신
  → Scene 렌더링
```

## 시각 디자인

- 바닥은 짙은 테니스 그린으로 바꾸고 크림색 라인 Geometry를 코트 위에 배치한다.
- 벽돌은 초록색 계열의 밝기 차이를 사용해 행별 깊이를 구분한다.
- 공은 테니스공을 연상시키는 노란색을 유지한다.
- HUD는 반투명한 크림색 또는 어두운 녹색 카드로 구성한다.
- 파괴 효과는 외부 텍스처 없이 작은 BoxGeometry 조각으로 표현한다.
- 3D 모드에서는 그림자와 원근감을 강조하고, 2D 모드에서는 전체 게임판의 판독성을 우선한다.

## 설정

벽돌 행·열·간격·크기·점수, 초기 목숨, 파편 수명과 개수는 `config/gameConfig.ts`에서 변경할 수 있게 한다. 학습 목적에 맞게 값과 코드의 연결 관계를 README에 설명한다.

## 오류 및 자원 관리

- 존재하지 않거나 이미 제거된 벽돌은 다시 제거하지 않는다.
- 게임 재시작 시 이전 파편과 벽돌 Mesh를 모두 정리한다.
- `dispose()`는 벽돌, 파편, 코트 장식의 Geometry와 Material을 해제한다.
- 상태가 `playing`이 아니면 공 충돌과 점수 변경을 수행하지 않는다.

## 검증

사용자 요청에 따라 테스트 파일은 생성하지 않는다. 다음 항목으로 검증한다.

- TypeScript strict 타입 검사
- Vite 프로덕션 빌드
- 데스크톱에서 시작, 벽돌 파괴, 목숨 감소, 게임오버, 다시 시작 확인
- 2D·3D 시점 전환 확인
- 모바일 크기에서 HUD와 버튼 배치 확인
- 브라우저 콘솔 오류 및 경고 확인

구현 변경은 기능 단위로 한글 커밋을 남기며, 사용자의 기존 `.gitignore` 변경은 포함하지 않는다.
